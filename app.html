Printer setup & printing

Setup is a one-time job. The home page has the same steps with screenshots.

1. Use Chrome or Edge

Printing uses WebUSB, which Firefox and Safari don't support. Open this page over HTTPS or http://localhost, not from a file:// path.

2. Turn off Editor Lite on the printer

While the green Editor Lite light is on, the printer pretends to be a USB flash drive. Hold the Editor Lite button for about a second until the light goes out.

3. Windows only: swap the driver with Zadig

Brother's driver blocks the browser, so give the printer the generic WinUSB driver instead. macOS and Linux usually don't need this.

  1. Download Zadig from zadig.akeo.ie and run it.
  2. Choose Options → List All Devices.
  3. Select QL-700 in the dropdown. The USB ID must read 04F9 2042. If it reads 2049, Editor Lite is still on — go back to step 2.
  4. Set the target driver to WinUSB and click Replace Driver.
  5. Unplug the printer and plug it back in.

Only change the QL-700 entry. Brother's own software won't print again until you restore its driver (step 6).

4. Connect

Click Connect printer (top right) and pick QL-700 in the browser's device list. The status line turns green. Next time, the printer reconnects by itself.

5. Print

  • Choose the tape in the toolbar to match the roll that's loaded: 62 mm or 29 mm continuous, or a die-cut size such as 29×90 mm address labels.
  • Design the label, then click Print.
  • A flashing red light on the printer almost always means the tape chosen here doesn't match the roll. Pick the matching size and press the printer's cut button to clear the error.

6. Restore Brother's driver

Open Device Manager, expand Universal Serial Bus devices, right-click QL-700 → Uninstall device with Attempt to remove the driver ticked, then replug the printer. If Windows doesn't restore Brother's driver by itself, reinstall it from Brother's website.

Which label roll is in the printer?

Pick the roll that's installed in your printer. You can change this later from the dropdown in the toolbar.

If the printer's status light turns red when trying to print, you may have selected the incorrect setting.

This browser can't print

Printing needs WebUSB, which only Google Chrome, Microsoft Edge and other Chromium browsers support.

You can still design and export labels here. To print, open this page in Chrome or Edge.

About

This is a label editor / printer tool for the Brother QL-700 printer that runs solely in the browser without the need for proprietary Brother software (eg. P-Touch).

Currently supports only the QL-700 printer. Feel free to open PRs or issues on GitHub.
