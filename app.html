How to set up & print

1. Requirements

  • Use Google Chrome or Microsoft Edge — WebUSB isn't supported in Firefox or Safari.
  • Open this page over HTTPS or http://localhost (not a file:// path). The home page has the full illustrated guide.
  • Windows: you'll install a generic driver once with Zadig (below). Mac/Linux usually work without it.

2. Take the printer out of “Editor Lite” mode

The QL-700 has an Editor Lite button with a green LED. While it's lit, the printer only shows up as a USB flash drive and can't be driven. Press and hold the Editor Lite button (about 1 second) until the green LED turns off.

3. Install the WinUSB driver with Zadig (Windows only)

Chrome can only reach the printer through the generic WinUSB driver, so you swap Brother's driver once:

  1. Download Zadig from zadig.akeo.ie and run it.
  2. Menu → Options → List All Devices.
  3. In the dropdown, select QL-700. Confirm the USB ID reads 04F9 2042 — not 2049 (that's the flash-drive mode from step 2; finish step 2 first).
  4. Set the target driver on the right to WinUSB, then click Replace Driver (or Install Driver).
  5. Unplug and replug the printer's USB cable.

⚠ This replaces Brother's driver, so Brother's own P-touch / QL software won't print until you revert it (see step 6). Be careful to pick QL-700 in Zadig and nothing else.

4. Connect

Click Connect (top-right) and choose QL-700 in the browser's device picker. The button becomes Reconnect once linked, and it reconnects automatically next time.

5. Choose your label & print

  • Pick the tape in the top-left dropdown to match the roll you loaded: 62mm / 29mm continuous, or a die-cut size such as 29×90mm address labels.
  • Design your label, then click Print.
  • A red flashing LED almost always means the tape you selected doesn't match the roll that's loaded — pick the matching size.

6. Going back to Brother's software

Open Device Manager, find QL-700 under “Universal Serial Bus devices”, right-click → Uninstall device (tick “Delete the driver software”), then re-run Brother's installer to restore their driver.

Use Chrome to print

This app connects to the QL-700 with WebUSB, which only works in Google Chrome, Microsoft Edge, or another Chromium-based browser.

Your current browser doesn't support it, so printing won't work here. Please open this page in Google Chrome to connect and print.

You can still design and export labels in this browser — only printing is unavailable.

About

QL-700 Label Studio

A WebUSB label designer for the Brother QL-700. Design multi-element labels, use templates with variable data, and print with cut lines — no drivers beyond WinUSB.

Files are saved as versioned JSON (format ql700-label v1). Your workspace is auto-saved in this browser.
