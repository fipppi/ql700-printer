For the Brother QL-700 · Chrome & Edge

Design and print labels
straight from your browser.

QL-700 Label Studio is a free label designer that talks to your Brother QL-700 over WebUSB. No Brother drivers, no P-touch Editor, nothing to install — it runs entirely on your own device, works offline once loaded, and never sends your labels anywhere.

Open Label Studio → Set up the printer first

⚠ This browser doesn't support WebUSB. You can still design and export labels, but to print you'll need Google Chrome or Microsoft Edge.

Why this exists

The QL-700 ships with P-touch Editor Lite, a tiny program that lives on the printer's built-in USB drive. It's Windows-only, clunky, and can't do variable data, batch runs or multi-segment labels. Brother's full software is heavyweight and still needs their driver stack. Label Studio replaces both with a single web page: a layered editor and a raster driver that speaks the printer's native ESC/P protocol directly over USB.

Nothing to install

Open the link, plug in the printer, print. On Windows you swap one USB driver, once (see setup below).

Private & offline

Everything runs in the browser tab. Your labels stay on your machine, and the app keeps working with no internet after the first visit.

Made for real jobs

Cut lines, templates with {{variables}}, batch printing from a data table, and one-click import of eBay shipping PDFs.

How it works

  1. Pick your tape

    Top-left dropdown. Match the roll that's loaded: 62 mm or 29 mm continuous (you set the length by dragging the label's edge), or a fixed-size die-cut label such as 29×90 mm address or 62×100 mm shipping.

  2. Design the label

    Add text, symbols, images (auto-dithered to black & white) and shapes. Drag to move, use the handles to scale or stretch, press R to rotate. Layers, rulers, grid, guides and snapping work like a normal design tool. Ctrl+Z undoes.

  3. Split it with cut lines (optional)

    Click ✂ Cut line to divide one design into segments. The printer prints each segment and cuts between them — perfect for a sender + receiver pair, or a run of identical labels.

  4. Connect and print

    Click Connect (top-right), choose QL-700 in the browser's device picker, then Print. Chrome remembers the printer, so next time it reconnects on its own.

Going further

Templates & batch printing

Type {{name}}, {{sku}} — any {{variable}} — into a text element, then open File → Template data…. Fill a row per label (or paste rows in the Free edit box using | between columns) and print them all through the print queue, one at a time or automatically.

Shipping PDFs

File → Import shipping PDF… reads the address page of an eBay-style shipping PDF and builds a label with the Send from block, a cut, then the Deliver to block. Select several PDFs at once and print them with Print selected labels.

Multiple labels & files

The left panel holds as many labels as you like. Everything auto-saves in your browser. Export a label or the whole project as JSON to back it up or move it to another machine, and Import it back.

Install it as an app

In Chrome, click the Install icon in the address bar to get a standalone window and a Start-menu / dock entry. It works offline.

Setting up the printer

One-time. Takes about five minutes on Windows; macOS and Linux usually need only steps 1 and 2.

1 Use Chrome or Edge

WebUSB is only available in Chromium browsers — Google Chrome, Microsoft Edge, Brave, Opera, etc. Firefox and Safari can design labels but cannot print.

2 Turn off “Editor Lite” mode on the printer

The QL-700 has an Editor Lite button with a green LED. While it's lit, the printer pretends to be a USB flash drive and can't be driven. Hold the button for about one second until the green LED goes out. The printer remembers this setting.

3 Windows only: install the WinUSB driver with Zadig

Windows attaches Brother's printer driver to the QL-700, which blocks the browser from talking to it. Zadig swaps it for the generic WinUSB driver:

  1. Download Zadig from zadig.akeo.ie and run it (no installer).
  2. Menu Options → List All Devices.
  3. In the dropdown pick QL-700. Check the USB ID reads 04F9 2042. If it reads 2049 the printer is still in Editor Lite mode — go back to step 2.
  4. Make sure the target driver (right-hand box) says WinUSB, then click Replace Driver.
  5. Unplug the USB cable and plug it back in.

⚠ Pick QL-700 in Zadig and nothing else — replacing the driver of a different device can break it. This also means Brother's own software won't print until you revert the driver.

4 Connect

Open Label Studio, click Connect in the top-right and choose QL-700. The status line turns green with the printer's name and Print lights up. Load a roll, pick the matching tape in the dropdown, and print a test label.

Going back to Brother's driver

If you want to use P-touch Editor or Brother's printer driver again, put the original driver back. The two can't be active at the same time, but switching either way is a few clicks.

  1. Unplug the printer, then plug it back in so it's listed.
  2. Open Device Manager (right-click Start → Device Manager).
  3. Expand Universal Serial Bus devices and find QL-700.
  4. Right-click it → Uninstall device. Tick “Attempt to remove the driver for this device” (older Windows: “Delete the driver software”), then Uninstall.
  5. Unplug and replug the printer. Windows will either restore Brother's driver automatically or leave it under “Other devices”.
  6. If it's not restored, re-run Brother's installer from support.brother.com (search “QL-700 full driver & software package”).

To use Label Studio again later, just repeat the Zadig step. Editor Lite mode is unaffected by any of this.

Troubleshooting

The QL-700 doesn't appear in the browser's device picker

In order: (1) the Editor Lite LED must be off; (2) on Windows the WinUSB driver must be installed via Zadig; (3) try a different USB port or cable — some hubs drop WebUSB devices; (4) close any Brother software that may be holding the printer open.

The printer's LED flashes red

Almost always the tape you selected in the app doesn't match the roll that's loaded — or the roll is out / the cover is open. Pick the matching size and try again. A press of the cut button clears the error.

Zadig shows USB ID 04F9 2049 instead of 2042

2049 is the Editor Lite “mass storage” personality. Hold the Editor Lite button until its LED turns off, replug the printer, and refresh Zadig's device list.

Text looks jagged or images look speckled

The QL-700 is a 300 dpi one-bit thermal printer: every dot is either black or white. Images are converted with Floyd–Steinberg dithering, which looks speckled up close but reads correctly at arm's length. For crisp results use large bold text, and avoid thin lines below about 2 dots.

My labels disappeared after switching computers or browsers

The workspace is saved in the browser's local storage, which is per browser and per site address. Use File → Export project… to save it as JSON and Import… on the other machine.

Does it work with other Brother QL printers?

It's written and tested for the QL-700 (300 dpi, 62 mm head). The raster protocol is shared across the QL family, so close relatives like the QL-500/550/570 may work with the same driver swap, but they're untested.
